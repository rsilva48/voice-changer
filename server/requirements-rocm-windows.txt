#   - ROCm EP removed since ORT 1.23
#   - MIGraphX EP is Linux-only

#     Access Violation when running real voice changer ONNX models on RDNA3/4
#     (both 1.20.0 and 1.24.2 confirmed crashing on RX 9070 XT)
# Plain CPU onnxruntime is used: ONNX models (embedder, pitch extractor,
# inferencer) run on CPU while PyTorch .pth models use GPU via ROCm/HIP.
